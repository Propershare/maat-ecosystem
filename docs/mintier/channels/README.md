# Mintier Channels Operating Model

Purpose: Run a unified multi-channel communication system where one core message is adapted per platform without losing voice, truth, or intent.

## Channel Roles

- WhatsApp
  - Role: High-intent direct conversations and warm conversion
  - Primary use: Direct outreach, follow-ups, concise updates
  - Cadence: 1 post/day + reactive replies

- Telegram
  - Role: Announcement + community feed
  - Primary use: Product updates, launch notes, call-to-actions
  - Cadence: 1-2 posts/day

- Discord
  - Role: Community engagement + support
  - Primary use: Q&A, feedback loops, dev/community prompts
  - Cadence: 1 post/day + active threaded follow-up

- X (Twitter)
  - Role: Top-of-funnel awareness
  - Primary use: Short insights, hooks, clips, links to deeper channels
  - Cadence: 2 posts/day

## Content Pillars

1. Education
   - Practical insights, how-to steps, breakdowns
2. Product Updates
   - Features, releases, bugfixes, roadmap snapshots
3. Proof
   - Results, demos, testimonials, case snippets
4. Culture
   - Mission, values, behind-the-scenes, team moments
5. CTA
   - Clear next action: join, reply, test, book, share

## Voice and Style by Platform

- WhatsApp: concise, personal, action-oriented, no fluff
- Telegram: clear and structured, slightly more context
- Discord: conversational, community-first, invite discussion
- X: tight hooks, high signal, one clear point per post

## Publishing Workflow

1. Draft one canonical source post from the day’s pillar/theme
2. Adapt to each platform format
3. Run governance check for medium/high-risk claims
4. Schedule or publish
5. Monitor responses and log important learnings

## Governance and Escalation

Risk classes:
- Low: educational/general updates
- Medium: comparative or performance claims
- High: legal/financial/sensitive messaging

Escalation:
- Medium: owner review before posting
- High: Tehuti Guard policy decision before posting

## Ownership

- Channel lead: Mintier operator
- Backup owner: designated ops/admin
- Response SLA target:
  - High-intent DMs: <2 hours during active hours
  - Community questions: <6 hours

## Cadence Baseline

- Daily:
  - WhatsApp: 1
  - Telegram: 1-2
  - Discord: 1 + engagement follow-ups
  - X: 2

- Weekly:
  - 1 recap thread/post with strongest insight + CTA

## Success Criteria

- Consistent cadence maintained for 14 days
- Engagement trend improves week-over-week
- Response latency remains within SLA
- CTA conversions tracked weekly
