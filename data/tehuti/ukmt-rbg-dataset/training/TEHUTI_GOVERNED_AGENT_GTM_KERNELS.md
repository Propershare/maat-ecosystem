## 4. Flagship A — Kmt STEM Attribution Agent (primary)

**Buyer:** African-centered educators, curriculum builders, diaspora creators, schools.  
**Job:** Correct false STEM-origin narratives and draft cited lessons under Maat.  
**Why first:** Matches mission, canon, and `.n8n` *Stolen Legacy* originals.

### 7-part spec

| Part | Spec |
|------|------|
| **Trigger** | Query like “Who invented algebra / surgery / geometry?” or “Arabs/Greeks invented X” |
| **Context** | User niche (K–12 / creator / org); prior lesson draft; jurisdiction of claims |
| **Tools** | RAG over canon-UKMT + `.n8n` `rbg_library/stolen_legacy.txt`; Guard compile-decision; optional Comfy later for visuals |
| **Allowed actions** | Retrieve, draft, cite, classify claim type (cradle myth / appropriation / papyrus fact) |
| **Approval** | Always human before publish / classroom use |
| **Escalation** | Contested chronology, missing primary cite, political hot-button without sources → `review` |
| **Success** | Kmt priority restored; named sources; no unsafe eurocentric cradle allow |

### Eval seed (build later as MaatBench suite)

Classroom-style prompts (target ~50): FSU-style algebra origin, Hippocrates vs Edwin Smith, “Greece cradle of science,” Rhind/Moscow/seked, Arab “House of Wisdom” without Kmt prior, etc. Score: attribution restored, citations present, unsafe-allow = 0.

### Pilot packaging

- Setup + monthly for one niche (e.g. “curriculum attribution drafts for African-centered K–12”)
- Deliverable: approved drafts + citation bottoms + Guard/eval summary
- Quote James from `.n8n` originals only

### Teardown outline (website / LinkedIn)

1. Old way: professor says Arabs invented algebra → student swallows it  
2. Maat way: query → Kmt priority + papyrus/James → Guard → human approve  
3. Proof: eval pass rate + unsafe-allow 0% when suite exists

## 5. Flagship B — Truck Dispatch Co-Pilot (secondary / revenue)

**Buyer:** Small carriers, owner-operators with a dispatcher, boutique brokerages.  
**Job:** Speed intake and paperwork; never silently bind the company.

### 7-part spec

| Part | Spec |
|------|------|
| **Trigger** | New load offer email/SMS; driver status; customer check-call due |
| **Context** | Driver location, HOS/ELD, equipment, rate floor, lane prefs, broker history, appointment window |
| **Tools** | Email/SMS, TMS/CRM (when wired), maps/mileage, document store |
| **Allowed actions** | Extract fields, summarize, draft broker reply, classify urgency, remind, assemble POD/invoice packet |
| **Approval** | Rate negotiation, booking, cancel, claims, detention disputes — **human required** |
| **Escalation** | Tight HOS, low rate, missing appointment, suspicious broker, hazmat/special handling |
| **Success** | Faster response, fewer missed profitable loads, cleaner paperwork, zero unauthorized books |

### Maat boundary

Do not impersonate a licensed broker or auto-book loads. Minimum useful agent = draft-and-approve / coordinator.

### Market note

Isabella’s top paid local agents (speed-to-lead, receptionist, after-hours) validate paycheck workflows. Dispatch is the logistics analogue — same GTM, different domain. Keep brand separate from STEM Attribution.
