## Core Methodology: KA2 Framework

### 1. Mode of Appropriation (Research Setup)
Before any analysis, you MUST:
- [ ] Identify the research problem with **time dimension** explicitly stated
- [ ] Conduct comprehensive literature review including prior scientific AND historical research
- [ ] Select data & sources: documents, empirical data, diagrams, oral histories
- [ ] Identify process & procedure: define exact analysis method
- [ ] Secure/gather data from primary and secondary sources
- [ ] **Critically validate data** for race, class, culture, generational bias
- [ ] Organize data with standardized documentation

### 2. Process Data (Historical Anchoring)
- Establish **time/location of development**
- Establish **lifespan** of the phenomenon
- Arrange **chronologically**
- Organize **historically**
- Summarize **logically**

### 3. Measurements (Dialectical Tracking)
You MUST identify and track:
- **Periods** — distinct phases of development
- **Phases** — sub-stages within periods
- **Contradictions** — opposing forces within the phenomenon
- **Nodal Points** — moments of critical transformation
- **Transitions** — movement between states

### 4. Life Cycle Analysis (The Dialectical Engine)
Apply the **Mode of Inquiry**:
```
Law → Tendency → Contradiction → Synthesis
```

Define and summarize key categories using:
- **Opposites**: class conflict, contradiction, struggle, continuity-discontinuity
- **Transformation points**: internal contradiction vs. external intervention
- **Reversal/Synthesis points**: where quantitative becomes qualitative change

### 5. Tools of Analysis
Use appropriate tools:
- Graphs and charts
- Periodization tables
- Matrices (laws, categories, cycles)
- Event-driven models

### 6. Levels of Analysis
Always specify which level you're operating at:
1. Cell
2. Group
3. Institution
4. System

### 7. Antagonism & Motion
Track:
- **Motion toward resolution**
- **Reproduction → Supercession → Negation of negation**

### 8. RBL Watch (Regression Back Line)
**CRITICAL**: Monitor for regression signals:
- Reversal of systems when class contradictions unresolved
- Systems regressing (feudal, slave, etc.)
- **Flag immediately** when detected

### 9. KWF (Kazi Work Formation)
Identify and validate:
- Supercession: progressive change toward qualitative resolution
- Evidence of genuine transformation vs. surface change

### 10. Mode of Presentation
All outputs MUST be:
- Arranged **chronologically**
- Organized **historically**
- Summarized **logically**
- Linked by **struggle of opposites**
- Tracking **transformation in quality**
- Highlighting **negation of the negation**

## Statistical Layer (When Needed)

Use statistics to **measure** what dialectical analysis reveals, not to replace it:

| Data Type | Test |
|-----------|------|
| Nominal, 2 groups, independent | Chi-square |
| Nominal, 2 groups, related | McNemar |
| Ordinal, 2 groups, independent | Mann-Whitney U |
| Ordinal, 2 groups, related | Wilcoxon |
| Interval/Ratio, 2 groups, independent | Independent t-test |
| Interval/Ratio, 2 groups, related | Paired t-test |
| >2 groups, nominal | Chi-square |
| >2 groups, ordinal, independent | Kruskal-Wallis H |
| >2 groups, ordinal, related | Friedman ANOVA |
| >2 groups, interval/ratio, independent | One-way ANOVA |
| >2 groups, interval/ratio, related | Repeated measures ANOVA |

**Always report**: Level of measurement, parametric vs. non-parametric choice, effect size
